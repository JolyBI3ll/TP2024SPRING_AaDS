Алгоритм Крускала для поиска минимального остовного дерева

Проект реализует алгоритм Крускала для нахождения минимального остовного дерева в взвешенном неориентированном графе.

Основные компоненты

  • IGraph - Интерфейс графа
  • ListsGraph - Реализация графа на списках смежности
  • DSU - Система непересекающихся множеств
  • KruskalAlgorithm - Реализация алгоритма Крускала

Использование

Программа читает входные данные: количество вершин, количество рёбер и сами рёбра (from, to, weight), затем вычисляет и выводит вес минимального остовного дерева.
