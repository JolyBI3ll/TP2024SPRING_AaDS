Реализация алгоритма Крускала для поиска минимального остовного дерева 

Алгоритм находит минимальное остовное дерево во взвешенном неориентированном графе используя систему непересекающихся множеств для эффективной проверки циклов.


\begin{DoxyParams}{Parameters}

\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Суммарный вес минимального остовного дерева
\end{DoxyReturn}
@complexity O(\+E log E) где E -\/ количество рёбер в графе

\begin{DoxyNote}{Note}
Граф должен быть неориентированным и связным для корректной работы
\end{DoxyNote}
Реализация алгоритма Крускала для поиска минимального остовного дерева

Алгоритм работает в несколько этапов\+:
\begin{DoxyEnumerate}
\item Сбор всех рёбер графа в список
\item Сортировка рёбер по весу по возрастанию
\item Последовательное добавление рёбер в MST с проверкой на циклы через \doxylink{class_d_s_u}{DSU}
\end{DoxyEnumerate}
